# Code Sandbox

Online code sandbox with **editor**, **terminal**, and **live preview**.
Build interactive HTML/JS apps (including iPhone-style UIs), run Python, and more.

## Features

- Monaco editor (VS Code engine)
- Live HTML preview (interactive apps, iPhone mock sample included)
- Terminal (xterm.js)
- Python via Pyodide (in-browser)
- JavaScript execution
- **Erase Code** and **Clear Terminal** buttons
- Mobile-first UI (iPhone-friendly tabs + bottom Run bar)
- Samples: iPhone Home, Python, JavaScript, HTML

## Deploy on Vercel

1. Import `Dennisbed1234/flutter-sandbox`
2. Framework: **Vite**
3. Build command: `npm run build`
4. Output: `dist`

## Local

```bash
npm install
npm run dev
```
